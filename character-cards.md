# Character Cards

These repositories generally have NSFW filters, pages loaded may not be safe for work.

Here are some repositories where you can find character cards:

*   [Character Archive](https://char-archive.evulid.cc/#/)
    * Blurs nsfw by default, at least.
    * This is an aggregate archive of created works going back several years.
*   [Janny.AI (unofficial)](https://jannyai.com/characters/search)
    * Separate link for janny.ai browse: [https://jannyai.com/](https://jannyai.com/)
*   [SillyCards](https://sillycards.co/presets)
*   [Backyard AI](https://backyard.ai/hub)
*   [Chub.ai Character Cards](https://chub.ai/search?excludetopics=&first=20&page=1&namespace=characters&search=&include_forks=true&nsfw=false&nsfw_only=false&require_custom_prompt=false&require_example_dialogues=false&require_images=false&require_expressions=false&nsfl=false&asc=false&min_ai_rating=0&min_tokens=50&max_tokens=100000&chub=true&require_lore=false&exclude_mine=true&require_lore_embedded=false&require_lore_linked=false&language=&sort=default&min_tags=2&topics=&special_mode=&name_like=&only_mine=&inclusive_or=false&recommended_verified=false&require_alternate_greetings=false&max_days_ago=&min_users_chatted=)
*   [CharacterHub.org / Chub.AI Legacy Character Card UI](https://www.characterhub.org/characters?search=&first=50&topics=&excludetopics=&page=1&sort=default&venus=false&min_tokens=50&first=50&page=1)
*   [Pygmalion AI (need account)](https://pygmalion.chat/explore)
*   [AI Character Cards](https://aicharactercards.com/)
*   [WyvernChat Characters](https://app.wyvern.chat/explore?tab=characters&char_sort=dateCreated)
